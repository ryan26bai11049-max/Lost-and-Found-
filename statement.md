# Campus Lost & Found Management System

## 1. Problem Statement

In a college campus, students and staff may lose personal belongings such as ID cards, wallets, books, bags, keys, or electronic devices. Similarly, people who find these items may not know how to report them or connect them with their owners.

The **Campus Lost & Found Management System** provides a simple terminal-based solution for recording lost and found items in one place. The system allows users to report items, search reported items, and compare lost and found item details to identify possible matches.

The project aims to make the process of reporting and finding misplaced items more organized and easier to manage.

---

## 2. Scope of the Project

The project is designed as a **terminal-based Python application** for managing lost and found items within a campus environment.

The scope includes:

* Recording lost item information.
* Recording found item information.
* Searching for reported items.
* Comparing lost and found items.
* Calculating a simple match score for possible matches.
* Viewing reported items.
* Updating the status of reported items.
* Validating user input.
* Displaying results through the terminal.

The project focuses on basic Python programming and problem-solving techniques. It does not include a graphical user interface, online database, mobile application, or online communication system.

---

## 3. Target Users

The main target users of the system are:

### Students

Students can report items they have lost or found on campus and search for possible matches.

### Teaching and Non-Teaching Staff

Staff members can report lost or found belongings and search the available records.

### Campus Lost & Found Personnel

Personnel responsible for managing lost belongings can use the system to maintain and update item records.

---

## 4. High-Level Features

### 4.1 Lost Item Reporting

Users can record details of an item they have lost, including its name, category, colour, location, date, and description.

### 4.2 Found Item Reporting

Users can record details of an item they have found on campus.

### 4.3 Item Search

Users can search reported items using information such as item name, category, colour, or location.

### 4.4 Possible Match Detection

The system compares lost and found item details and calculates a simple match score based on common attributes.

### 4.5 Item Status Management

Users can update an item's status, such as Lost, Found, Matched, or Claimed.

### 4.6 Item Records

Users can view the currently recorded lost and found items.

### 4.7 Input Validation

The system checks user input and handles common invalid entries such as empty values, invalid choices, and incorrect item IDs.

---

## 5. Project Objective

The main objective of the project is to apply problem-solving and Python programming concepts to create a simple practical system for managing campus lost and found items.

The project demonstrates the use of **functions, conditional statements, loops, lists, dictionaries, searching, sorting, input validation, and basic algorithm design**.
